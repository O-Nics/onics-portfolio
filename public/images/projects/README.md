# Images des projets

Placez vos images de projets dans ce dossier, organisées par projet.

## Structure recommandée

```
images/projects/
├── nom-du-projet-1/
│   ├── screenshot-1.jpg
│   ├── screenshot-2.jpg
│   └── logo.png
├── nom-du-projet-2/
│   ├── hero.jpg
│   └── gallery/
│       ├── image-1.jpg
│       └── image-2.jpg
```

## Formats recommandés

- **JPG/JPEG** : Pour les photos et screenshots
- **PNG** : Pour les logos et images avec transparence
- **WebP** : Format moderne, léger et de bonne qualité

## Optimisation

Pensez à optimiser vos images avant de les ajouter :
- Utilisez des outils comme TinyPNG, ImageOptim, ou Squoosh
- Cibles : ~200KB max pour les vignettes, ~500KB max pour les grandes images
